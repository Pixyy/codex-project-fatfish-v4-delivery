# 大肥鱼 v4 · Codex 工程演示

一只可在 Q 版与成熟版之间切换、会动、能聊天的本地鲸鱼娘。由 Codex 在本次对话中完成界面、原生桌宠、模型接入、任务服务与验证脚本；形象由社区资源与 GPT Image 二创提供。

## 先体验

**完整交付包解压后，先双击「先看这里.html」**：无需 Python 或账号，就能切换形态和播放动作。此页是离线形象预览，未调用 AI。

要使用完整程序，请先安装 **Python 3.10+（64 位）**：

- **启动桌宠**：双击同名 `.bat`（Windows）或 `.command`（macOS）。首次自动安装 Qt 组件。
- **启动养成台**：双击「启动养成台」（源码目录中为「启动大肥鱼」）。浏览器自动打开本机界面。
- **真实聊天**：「和她说说话」→「接入 DeepSeek」→ 登录官方开放平台创建 API Key → 粘贴 Key → 检测并开始聊天。
- **网页任务**：首次先运行「安装浏览器」，再在「出去逛逛」发起任务。
- **遇到问题**：运行「诊断环境」，或在设置中下载环境诊断报告。

终端：`python launcher.py` / `python launcher.py --desktop`。

## 这次可以看什么

| 能力 | 怎么体验 |
| --- | --- |
| 两种形态与动画 | Q 版 / 成熟版切换，挥手、眨眼、跳跃、投喂、睡觉 |
| 原生桌宠 | 拖拽；双击聊天；右键变身、缩放、置顶；散步默认关闭 |
| DeepSeek 接入 | 官网入口、只写 Key、当前模型列表、余额检测、小请求验通、断开并忘记 |
| 浏览任务 | 公开 HTTPS 网页读取与截图；配置模型后可做有限步数的站内探索 |
| 消息与手机 | 已授权 OneBot 的 QQ 自动回复；企业微信群发送；可选 Android ADB 固定动作 |

真实模型请求按服务商 API 规则计费。本项目采用 **API Key 接入**，官网登录状态不会自动授权本程序；官方 Harness 的账号授权需在 Harness 内使用。本项目不接收官网登录密码或 Cookie。

## 数据与边界

配置、聊天和截图保存在本项目 `data/`；Key 为本机文件保存，未加密，页面不回显。模型会收到当前会话近期内容；预设体验记录不会作为真实模型上下文。交付包不包含 `data/`、用户密钥或聊天记录。

当前已验证本机 HTTP、浏览器页面、真实公开网页和 Qt 离屏交互。未取得真实商业模型 Key / QQ / 微信凭据；这些接入链路使用明确的本地测试服务验证。Windows/macOS 桌面合成器和 Android 真机尚未实测。

成熟版为六姿态与程序过渡，不是 Live2D。微信支持企业微信群机器人发送，不支持个人微信登录。角色为非官方、非商业社区二创，来源与许可见 [ATTRIBUTION.md](ATTRIBUTION.md)。
