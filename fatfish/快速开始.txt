大肥鱼 v4 · Codex 工程演示

1. 解压完整交付包，先打开「先看这里.html」：无需安装即可预览两种形态和动作。
2. 完整程序需要 Python 3.10+（64 位）。Windows 安装时勾选 Add Python to PATH。
3. 双击「启动桌宠」；首次会自动安装组件。拖拽移动、双击聊天、右键变身。
4. 真实聊天：在养成台点击「接入 DeepSeek」，到官方平台登录并创建自己的 API Key，回填后检测。
5. 官网账号登录不会自动授权本项目；API 按官方规则计费。无 Key 时是明确标注的预设体验。
6. 读网页前先运行「安装浏览器」；遇到问题运行「诊断环境」。

默认不开启散步或外部自动回复。源码、素材来源与验证结果随包提供。
不要把自己运行后生成的 data 文件夹转发给别人，里面可能有自己的 Key 和聊天记录。
