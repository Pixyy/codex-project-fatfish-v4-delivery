## 为何采用这条路线

现有聊天、QQ 和浏览服务是 Python 本地应用。把 Electron 插件整套拼进来会引入第二套配置、窗口生命周期和插件权限。这里复用动作素材及数据格式，用较小的 Qt Essentials 组件实现独立桌宠，继续调用原来的本机 HTTP 接口。

网页 Canvas 和 Qt 都读取 `static/pets/manifest.json`。Q 版使用多帧动画，成熟版使用六个姿态加眨眼、呼吸和轻跳效果；两者之间是 0.4 秒交叉淡入与星光过渡，**不是骨骼变形或完整 Live2D 模型**。

## 使用方式

安装 Python 3.10+，解压后双击 `启动桌宠.bat` / `启动桌宠.command`。首次自动安装 PySide6-Essentials 至本项目 `data/desktop-python`，后续离线即可显示和播放动作。真实 AI 聊天仍需自己的模型配置。

- 左键按住：拖拽；位置限制在显示器可用区域。
- 单击：挥手打招呼；双击：打开原生聊天框。
- 右键：切换形态、喂饭、睡觉、动作开关、大小、置顶、散步、回到屏幕、打开养成台或退出。
- Q 版：逐帧待机、眨眼、挥手、跳跃、左右走动、思考、工作和 16 向看鼠标。
- 成熟版：六个已生成姿态，待机眨眼、挥手、思考、持碗开心、闭眼困倦；移动时仍以站姿轻移，没有完整走路帧。
- 默认不开散步。开启后才偶尔水平移动，不操作你的其他窗口。
- 动画暂停后不再推进动画帧；仍可主动切换形态和动作姿态。
- 窗口透明区域通过 alpha 蒙版处理，减少遮挡桌面点击；气泡与窗口位置一同移动。
- 最小化到托盘仅在系统提供托盘时显示；若屏幕布局改变，可从右键菜单移回屏幕。
- 网页与桌宠共用形态和动画开关，约 4 秒同步。桌面位置、大小、置顶和散步设置单独保存。

等待回复时显示思考动作，后台任务进行时显示工作，任务结束会给动作和气泡提醒。聊天使用与网页相同的后端、会话和配置；预设体验始终标明非真实 AI。

## 退出行为

若由桌宠自己启动后端，退出时会暂停自动活动并结束该后端。若桌宠复用了已经打开的养成台服务，只退出悬浮窗口，原养成台会继续运行；可先用右键「暂停全部自动活动」。关闭形态不等于撤回已经发出的消息。

## 可扩展的素材格式

`static/pets/manifest.json` 中每种形态定义图集路径、网格、可选显示裁剪、动作帧坐标、每帧时长、循环标记和朝向数据。应用只读取固定项目资源，没有执行任意第三方皮肤代码的入口。今后可以添加更多有合法来源的姿态或独立建模的 Live2D/VRM 版本，再更换渲染器。

## 已知边界

当前环境没有真实桌面会话，原生测试使用 Qt offscreen 插件，验证透明与置顶标记、实际帧渲染、拖拽事件、菜单、缩放、形态保存、动画暂停和本机 HTTP 聊天。**没有验证 Windows/macOS 桌面合成器、全屏应用遮挡、系统托盘以及多显示器实机行为。**部分 Linux Wayland 桌面会限制应用置顶和自由定位，需要 X11/XWayland 或由窗口管理器配置。
