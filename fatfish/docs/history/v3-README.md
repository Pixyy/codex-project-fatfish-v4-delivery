# 大肥鱼 · 鲸鱼娘本地伙伴 v3

这次使用中文社区流行的 DeepSeek 娘形象：蓝色渐变长发、蓝瞳、鲸鳍耳、大鲸尾和蓝白女仆装。社区三视图作为参考，GPT Image 重画了透明立绘和三视图。形象属于非官方社区二创，来源见 [ATTRIBUTION.md](ATTRIBUTION.md)。

## 朋友喜欢桌宠，先从这里开始

安装 Python 3.10+ 后，解压整个包，双击 **启动桌宠.bat**（Windows）或 **启动桌宠.command**（macOS）。首次自动安装桌宠组件，之后会直接出现透明悬浮窗口：**拖拽移动、双击聊天、右键切换 Q 版／成熟版**。无需先开网页。默认不走动；右键可开启散步。

网页首页也能预览两种形态、挥手、跳跃、睡觉和变身；从已安装组件的本机养成台可以点击「启动独立桌宠」。无图形桌面会话的云环境会明确提示下载到本机运行。

Q 版复用深深桌宠的逐帧透明动画和 16 向朝向；成熟版根据社区三视图，由 GPT Image 绘制六姿态，配以眨眼、呼吸和切换效果。**这是精灵动画，不是 Live2D／3D 骨骼变形。** 素材和代码的选择、操作方式、退出行为及平台边界见 [桌宠资源与实现](docs/桌宠资源与实现.md)。

终端启动：`python launcher.py --desktop`。首次可单独运行 `python launcher.py --install-desktop` 安装组件。Windows/macOS 的原生桌面效果仍需实机验证；当前 Qt 离屏渲染与交互测试已通过。

## 最快开始

1. 解压整个文件夹，先安装 **Python 3.10 或更新版本**。Windows 安装 Python 时勾选 **Add Python to PATH**。
2. Windows 双击 **启动大肥鱼.bat**；macOS 双击 **启动大肥鱼.command**。Linux 或终端用户运行 `python3 launcher.py`。
3. 浏览器会自动打开本机页面。先喂饭、摸摸、聊天试试：默认是明确标注的**预设互动体验**，不用密钥，也不冒充真实 AI。
4. 要真实聊天：打开「给小鱼装大脑」，选「真实 AI」，填 API Key，点击「保存并检测连接」。默认 DeepSeek，也支持兼容 OpenAI 的服务。

聊天主程序只使用 Python 标准库，不需要先装 Node、Docker、数据库或执行环境变量命令。关闭启动窗口会停止服务；请先用界面左下角「暂停全部自动活动」结束后续动作。

如果 macOS 不允许直接运行 `.command`，在终端进入解压目录运行 `python3 launcher.py`。Windows 也可在终端使用 `py -3 launcher.py`。检测过旧版本进程时，新启动器会选择空闲端口，不把旧页面当作新版。

## 浏览网页

首次使用，双击 **安装浏览器.bat** 或 **安装浏览器.command**，按提示等安装结束，再打开大肥鱼。这会下载 Playwright 和 Chromium，约数百 MB，写入本项目 `data`，不修改系统 Python 包。

终端方式：

```bash
python launcher.py --install-browser
python launcher.py
```

在「出去逛逛」选择：

| 模式 | 实际行为 | 需要模型吗 |
| --- | --- | --- |
| 读取网页 | 打开公开 HTTPS 网页，提取文字并截图 | 不需要 |
| 自主探索 | 模型选择站内链接或滚动，根据实际读到的内容总结；默认最多 5 轮，最多可设 8 轮 | 需要支持 tool calling 的模型 |
| 网页视频 | 尝试播放已有 video 元素，停留指定时长，再检查播放进度 | 不需要 |

自主探索局限在起始网站及其子域名，浏览器不带个人登录信息，只提供只读动作。浏览器中的网络请求通过本项目的 HTTPS 传输层校验证书后渲染，以解决云环境代理 CA 与 Chromium 信任库不一致的问题；没有关闭 TLS 校验，也没有修改用户全局浏览器证书库。该传输层可能无法兼容某些登录站、流媒体、反爬机制和高度依赖跨域状态的页面。失败会保留原因，不会显示成成功。

任务可逐项停止，也可全局暂停。网络请求或已经发出的外部消息无法撤回；停止会阻止后续动作。重启时未完成任务会标记为中断，不会悄悄重跑。

## QQ 自动聊天

需要你先运行一个**自己授权并登录的 OneBot 11 协议端**，例如 NapCat。本项目不代登录 QQ、不收 QQ 密码，也不附带协议客户端。

1. 在协议端打开 HTTP API，配置 Access Token。
2. 在「连接聊天账号」填写 HTTP 地址，例如 `http://127.0.0.1:3000`，以及 Token，保存并检测登录。
3. 展开「如何让 QQ 消息传进来」，点击「显示本机回调配置」。
4. 把 URL 和 Secret 填入协议端的 HTTP 消息上报设置；消息格式选**消息段数组**。协议端必须支持 OneBot 11 的 `X-Signature: sha1=...` 签名。
5. 填写允许回复的好友或群号。在真实模型已配置后，打开自动回复开关并保存。

私聊仅处理允许列表中的好友。群内仅处理允许列表中的群，而且必须 @ 机器人。机器人自己的消息会忽略；重复消息编号去重，每会话有冷却时间，待处理队列有上限。网页聊天、不同 QQ 好友、不同群成员的对话分别保存。

回调默认只接本机，协议端和本应用建议放在同一台电脑。不需要把本机服务暴露到公网。OneBot 是社区协议，能否登录取决于协议端、账号和平台状态；不等于腾讯官方个人账号 API。

## 微信的可用范围

本版支持**企业微信群机器人发送文字**。在企业微信创建群机器人，将完整 Webhook 填入界面；发送一条消息成功后才标记「连接已验证」。

**不支持个人微信扫码登录、接收微信消息或自动回复个人微信。**企业微信群机器人不能替代这些能力，界面没有伪造登录入口。

## 手机 App 视频浏览

这是可选的 **Android ADB 固定动作通道**，不是视觉模型自主操作手机：

1. 在运行本应用的电脑安装 Android platform-tools，让 `adb` 可用。
2. 用 USB 连接手机，开启 USB 调试，在手机上允许这台电脑。
3. 在手机手动登录 App 并停留在视频推荐页。
4. 在「手机看视频」检测设备，选择哔哩哔哩或抖音，设定 10–120 秒并开始。

应用会打开选定 App，每 10 秒向上滑动一次，结束时截图。不点赞、评论、关注或发送消息，不让模型生成任意 shell 命令。动作日志不代表每条视频都已播放或看完。手机、App 界面和 ADB 不同，滑动行为可能需要适配；本环境没有 Android 设备，**真机执行未验证**。iPhone 不支持。

## 数据与配置

- 密钥通过页面填写，写入 `data/credentials.json`，创建时权限为 0600；在 Windows 上访问控制还取决于文件夹 ACL。它是本机文件，**不是加密保险库**。网页状态接口不回传密钥，密码框留空保留原值。
- SQLite 数据库为 `data/fish.db`，截图为 `data/artifacts/`；聊天明文保存在本机。模型请求会把当前会话近期内容发送给你选择的服务商。
- 网页对话保留最近 20 条作为模型上下文；不是无限上下文或语义长期记忆。界面可导出网页记录与最近任务。
- 服务只监听 `127.0.0.1`，校验 Host、写请求来源和会话令牌。QQ 回调独立校验 HMAC 签名。
- 环境变量 `FISH_MODEL_KEY`、`FISH_ONEBOT_URL`、`FISH_ONEBOT_TOKEN`、`FISH_WECOM_WEBHOOK` 仍可供开发者使用，设置后优先于页面值。
- 旧版记录和代码保留在当前开发工作区，不混入新版对话，也不打包用户数据。

## 验证

```bash
python -m unittest discover -s tests -v
python check_ui.py --live-browser
python check_desktop.py
FISH_LIVE_TESTS=1 python -m unittest discover -s tests -p test_browser_live.py -v
```

界面和集成测试在临时数据目录运行，不改你的配置。第一条使用显式测试接口验证模型、QQ 的 HTTP 收发与权限逻辑；它不证明真实账号已连接。后两条需要安装浏览组件，并实际访问公开 HTTPS 网页。详情见 [VALIDATION.md](VALIDATION.md)。

## 项目结构

`app.py`：本机 HTTP 接口；`store.py`：配置和记录；`brain.py`：模型与预设互动；`tasks.py`：浏览和 ADB；`channels.py`：QQ 与企业微信；`net.py`：HTTPS 校验；`launcher.py`：启动和可选安装；`static/`：界面与人设图；`desktop.py`：Qt 原生桌宠；`pet_core.py`：逐帧状态机；`static/pets/manifest.json`：两种渲染器共用的形态与动作。
