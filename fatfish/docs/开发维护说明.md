# 开发维护说明

运行需要 Python 3.10+。聊天服务只用标准库；Qt 和 Playwright 按需安装到项目 `data/`。没有必须先部署的云服务、Node 或 Docker。

| 文件 | 责任 |
| --- | --- |
| `app.py` / `app_identity.py` | loopback HTTP、写请求校验、不同解压副本的实例识别 |
| `provider.py` | 官方 DeepSeek 模型与余额查询、验通后保存、忘记 Key |
| `brain.py` | 模型快照、会话锁、预设 / 真实对话隔离、模型调用 |
| `store.py` | SQLite、配置、只写密钥；旧模型名兼容迁移 |
| `desktop.py` / `local_backend.py` | 原生桌宠、窗口与聊天、本机服务连接 |
| `pet_core.py` / `static/pet.js` | 共享动作配置的原生 / Canvas 播放器 |
| `tasks.py` / `channels.py` | 有限浏览 / ADB，QQ 签名回调 / 企业微信发送 |
| `doctor.py` | 不包含 Key、令牌和对话正文的诊断 |

## 重跑检查

```bash
python -m unittest discover -s tests -v
FISH_LIVE_TESTS=1 python -m unittest discover -s tests -v
python check_ui.py --live-browser
python check_connection_ui.py
python check_desktop.py
```

后两类 UI 检查需要预先安装对应组件：`python launcher.py --install-browser` / `python launcher.py --install-desktop`。检查使用临时数据目录；商业模型和 QQ 使用显式本地测试接口，不会把测试当作真实账号联调。

## 本轮修复重点

- 官方默认模型由旧别名更新为 `deepseek-flash`；旧官方配置兼容迁移，自定义网关的模型名保留。
- 官方日常聊天关闭思考模式，避免短输出预算被推理耗尽导致空回复。
- 接入失败保留原配置；余额检查和生成请求分别验证；错误码 401、402、429 分开说明。
- 检测过程中配置改变，不给新配置错误地盖上“已验证”状态。
- 形态等普通配置变更不再把环境变量 Key 顺带写进磁盘。
- 预设对话单独标记，不进入真实模型上下文；清空与发送共用会话锁。
- 防止 Ctrl+Enter 重复发送，保留等待期间输入的下一条草稿；增加等待提示。
- 原生聊天增加接入入口、共享历史和失败后输入恢复；避免旧轮询覆盖刚收到的回复。
- 后端按解压副本和数据目录识别，避免另一份大肥鱼复用当前客户的配置。

## 构建转发包

`python build_delivery.py` 生成分层交付包和可单独转发的离线介绍。介绍 PDF 由 `render_intro.py` 输出。`data/`、`.env`、旧版代码与缓存不打包；素材许可随包保留。请勿直接压缩运行后的整个目录发送给客户。
