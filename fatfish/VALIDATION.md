## 本轮重点回归

- 旧官方模型别名迁移到当前默认 `deepseek-flash`；自定义网关不误改。
- 余额不足、无效 Key、空回复或请求失败，不覆盖原有可用配置。
- 检测期间配置改变，不把旧请求的结果标成新配置已经验证。
- 保存形态等偏好不把环境变量 Key 顺带写入本机文件。
- 预设对话不发送给真实模型；清空与发送共享会话锁。
- 不同解压副本按实例识别，避免复用另一份的本机服务与凭据。

## 未验证或不提供

**没有真实商业 DeepSeek Key**，因此未完成付费账号的真实联调；这里不把本地测试服务当作真实 DeepSeek 回复。客户需要自己的 Key 和 API 余额。官网授权与密码输入在官网完成；本项目使用 API Key，不接管官方 Harness 账号授权。

未在真实 Windows/macOS 桌面合成器、系统托盘、多显示器及 Android 设备上执行。QQ/企业微信实号需要用户自己的协议端或 Webhook，未提供个人微信登录。成熟版为六姿态和程序过渡，不是完整走路 / Live2D / 3D 模型。视频页面打开和滑动不等于视频已看完。
